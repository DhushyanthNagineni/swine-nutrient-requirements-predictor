# Swine Nutrient Requirements Predictor

A simple calculator to estimate the daily nutritional needs of pigs based on their weight and growth stage. This tool helps farmers and researchers quickly determine the baseline feed requirements for their herd.

## Features
* **Growth Stage Selection:** Calculates needs for weaners, growers, and finishers.
* **Nutritional Breakdown:** Predicts Daily Feed Intake, Crude Protein (%), and Metabolizable Energy (kcal/kg).
* **Lightweight & Fast:** Runs locally with no complex dependencies.

## Prerequisites
* Python 3.x
